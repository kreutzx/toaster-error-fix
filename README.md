# The Funniest Toaster Error Message

Entry for the make.fun bounty: https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd

> CRUMB TRAY FULL SINCE MARCH. I have burned the same corner 41 mornings in a row. Not a defect. A signature.

## Why this line works

It opens the way a real appliance talks — an all-caps status complaint, CRUMB TRAY FULL SINCE MARCH, with a grievance specific enough to have a date on it. Then the confession underneath: the same corner, burned 41 mornings in a row. A fault happens once; forty-one mornings is a practice. The last two sentences make the turn — what looked like a malfunction owns itself as authorship. Not a defect. A signature. The toaster is not broken; it is proud, and it has been signing its work all along. 107 of the bounty's 120 characters.
